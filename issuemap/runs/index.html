Does a crux map beat a plain AI summary?

On its cruxes, yes, in both tests: the map named nearly twice as many of the decision-makers' own key considerations. Read as a whole, it was only a little ahead, and the grader still found the plain summary quicker to read.

Run 7 Nov 2026 · tool: issuemap 0.1 · scribe and baseline both run by Claude agents · grading blind, by a separate agent

How it was run

  • Fetch. A GitHub Actions workflow pulled every comment through the GitHub API.
  • Freeze. Seven summary comments were removed from the await thread, including the team's own summary, because they are the answer key. The rest was locked with a SHA-256 hash.
  • Seal. A separate agent pulled the crux list from what the decision-makers wrote before any mapping began: the lang team's write-up and Boats' decision posts for await, and the Inside Rust announcement for the LLM policy.
  • Map. Scribe agents read the thread in batches and pulled out claims, each with an exact quote. A script checked every quote. Claims were then merged into points, linked, and the cruxes named.
  • Rival. Another agent read the same frozen thread and wrote a plain summary with its own crux list.
  • Grade. A third agent scored both outputs against the sealed key, with the labels hidden.

What to keep in mind

  • The map is better at naming cruxes than at being read. The grader judged the 1,000-word summary the quicker way to see where the disagreement lay. The map's long point lists are complete but hard to scan.
  • Leakage is only partly controlled. The await debate is famous, so the model may know it already. The LLM-policy debate was decided after the model's training cutoff, but much of the arguing happened before it.
  • The answer keys are imperfect. Only part of the await write-up survives in an archive, since the rest needed JavaScript. The LLM-policy key is a blog post explaining the policy, not a summary of the thread, which is why both outputs score low there.
  • Small sample. Two debates and one grader. The result points in a direction; it doesn't prove anything.
  • One of the map's eight await cruxes, implicit await, was judged doubtful. It was a fringe idea that the moderators had ruled out of scope.
